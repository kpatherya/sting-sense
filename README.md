# Sting-Sense: Bus Route Ride and Traffic Mapping

Sting-Sense is a lightweight analysis and visualization repository for
Georgia Tech bus-route telemetry. It provides scripts to map route quality and
traffic congestion from CSV inputs and includes an interactive Streamlit app
for route-level exploration.

Project metadata: [CONTRIBUTING.md](CONTRIBUTING.md) · [CITATION.cff](CITATION.cff) · [LICENSE](LICENSE)

## Repository Layout

- `bus_routes_app.py`: Streamlit app for interactive route/hour filtering.
- `all_routes_viz.py`: static map generation from route road-condition CSVs.
- `all_routes_traffichourfilter.py`: map generation with hour-based filtering.
- `all_routes_timeseries.py`: map generation for multi-phase route-condition data.
- `real_data/`: route CSV inputs used by app and scripts.
- `map/`: generated map artifacts or map-related assets.

## Quick Start

1. Create and activate a Python environment.
2. Install dependencies.
3. Run the Streamlit app.

```bash
python3 -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
streamlit run bus_routes_app.py
```

Open the local URL printed by Streamlit (typically `http://localhost:8501`).

## Expected Input Data

The app and scripts expect route CSV files in `real_data/` with columns that
include latitude/longitude, timestamps, and route condition or congestion
fields.

Examples referenced in code include:
- `blue_traffic_mini.csv`
- `red_traffic_mini.csv`
- `green_traffic_merged.csv`
- `gold_traffic_merged.csv`

## Common Scripts

Run static route visualizations:

```bash
python all_routes_viz.py
python all_routes_traffichourfilter.py
python all_routes_timeseries.py
```

Note: some legacy scripts write outputs to a local path constant. Update that
output directory to a valid path on your machine before running.

## Output

- Interactive route map and summary statistics from Streamlit.
- HTML map artifacts generated by visualization scripts.

## Research Status

This is a research-stage codebase intended for iteration and demonstration, not
production transit operations.
